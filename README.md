# 🚗 Tienda E-Commerce de Vehículos

Una plataforma web interactiva que simula una tienda en línea para la venta de automóviles. El proyecto destaca por cargar la información de los vehículos de manera dinámica a través de un archivo de datos.

## 🛠️ Tecnologías utilizadas
* **HTML5:** Estructura semántica de la tienda (22.3% del código base).
* **CSS3:** Estilos visuales y diseño responsivo (36.1% del código base).
* **JavaScript:** Lógica de carrito, filtrado y renderizado dinámico (41.6% del código base).
* **JSON:** Almacenamiento y simulación de base de datos (`vehiculo.json`).
